# 就挖一勺 V13 · 双旅程整合版

一个自包含 HTML，保留两条完整玩法：**现代地球连续挖掘**和**地标地质考察**。不是把两份旧游戏嵌进 iframe，也不是切换地图后丢掉上一段进度。

## 从哪里开始

打开 `just_one_scoop_v13_complete.html`，开场依次选择：

1. **现代地球 · 地心远征**（默认）：保留 V11 的整颗地球。从地表出发，自由向任意方向开图，经地幔、外核、内核到地心，再挖向另一侧地表。
2. **地标地质 · 野外考察**：保留 V12 的考察营地、喜马拉雅、云南澄江、约金斯煤系、热河、大峡谷、洋中脊和马里亚纳海沟，共八个目的地。
3. 选择 **探索** 或 **地狱** 难度。

**玩法 × 难度 = 四个独立档位**。洞穴、角色位置、研究点、技能、标本、地区访问和任务进度分别保存。两种玩法共享同一套内容与代码，不共享奖励余额，避免跨难度刷资源。

第一次建议：**现代地球 → 探索 → 开始地心远征**。不用先解锁地标、研究全套防护或跳到实验场，便能从浅层开挖。

## 现代地球这次增加了什么

- 浅层出现若干不同的教学沉积环境窗口，可以发现相匹配的化石、矿物，记录层位，刷拭并提交研究报告。
- 深部转为高压矿物、地震学与铁合金研究数据；不会在地核刷新恐龙化石，也不把深部遥测说成实地采矿。
- 仓鼠使用 V12 的分层动作与状态标签；扫描、刷拭、开挖、研究、补给等动作与状态沿用统一系统。
- 勺子、化石刷、钻头、扫描仪、抽水泵、10 km 石铲、100 km 未来机均在现代主模式使用。工具的勺碗、尖端与碰撞同向。
- 研究技能、分析方法、矿物与年代档案不再局限于地标模式。
- **地心不是通关终点**。到达地心观测区后需要继续挖向另一侧，角色真正穿出另一侧地表才判定完成。
- 完成后保留完整路线、接力站与报告，可继续自由探索。

现代浅部地层是用于游戏的条件化生成，不是假装复刻某条真实地球钻孔；不把各地不同时代的岩石铺成全球统一的“年代楼层”。局部显示尺度经过压缩，地球全景按地理坐标投影。

## 接力站与方向辅助

到达相应深度后，沿玩家实际路线建立接力站。可以免费补给或回到**已经到达过**的站点；不会把未探索的地下直接解锁为传送目标。返回站点不重新随机生成世界。

界面顶部的 **“向地心”** 是可选罗盘锁向：

- 只锁定工具前进方向，仍需按住画面或移动键才会挖掘。
- 再点一次解除，恢复左右、上下及斜向自由探索。
- 到地心观测区后自动解除，按钮改为“向另一侧”。可再次启用返程方向辅助。
- 接近精确中心的观测区半径为 2 km（地理模型坐标），界面明确显示这一容差，不伪称整个区域重力恒为零。

## 难度区别

### 探索

自由开图，不因氧气与防护资源失败；深部所需幻想防护按探索模式借用。可以自行发展研究方法和装备，化石保护、实验和报告仍有意义。适合先体验完整旅程。

### 地狱

现代地球按当前环境逐步要求装备，不再要求开局就装备齐全：

| 环境阶段 | 主要准备方向 |
|---|---|
| 浅层 | 记录与观察；可以直接开始 |
| 深部地壳 | 生命支持、防尘与本层环境报告 |
| 超深钻探尺度 | 气体监测、支护 |
| 上地幔 | 高温、承压与幻想防护 |
| 过渡带 | 高压矿物研究与 XRD |
| 下地幔 | 深部科幻防护场 |
| 外核 | 防护场、闭环冷却 |
| 内核 | 深部防护、地心导航 |

这些阶段是游戏门槛，不是真实工程材料的可用深度。进入新阶段后重新测量环境；报告有效五分钟游戏时间。冲刺在扣充能前检查整段路径可能到达的最大深度，不能冲过装备门槛。可以原路退回；安全站与接力补给始终免费可用。

打开知识、研究、地图或菜单时停止危险资源消耗。加入闭环冷却与地心导航后，技能树为 **22 项**；原有 20 项研究/装备保留。研究点不是自动赠送所有技能，报告、实验和首次里程碑支持成长。

地标地狱难度保留 V12 的地区准入、海底承压、气体与支护条件。地标剖面中不使用跨千米科幻冲刺，避免破坏精细考察玩法。

## 地图

- **洞穴路线**：显示本档当前区域真正挖开的形状，鼠标滚轮、双指、加减按钮缩放，拖动平移，“适应全部”“回到玩家”。
- **地球全景**：现代模式把实际挖掘路线投影到地球圈层；浅层线路按比例本来就薄，可以放大观察。
- 地标的局部重建坐标不伪装成穿地球路线，地标地图中全地球仅作圈层参考。
- 现代顶部“远征站”查看阶段、接力站与研究入口；地标的旗帜打开地区选择。

## 操作

| 输入 | 功能 |
|---|---|
| 鼠标 / 单指按住方向 | 持续挖掘；在画面边缘保持按住继续开图 |
| WASD / 方向键 | 向任意方向移动并挖掘 |
| 1—7 | 切换工具 |
| R | 扫描附近线索 |
| E | 研究附近对象 |
| K | 科学手册与实验 |
| M | 双地图 |
| Esc | 关闭当前面板 |
| 顶部“玩法”图标 | 返回开场选择；自动保留当前档位 |
| 罗盘锁向 | 可选方向辅助，不是自动游戏 |

普通发现提示约 4.5 秒自动收起，不抢挖掘输入。详细知识页只在主动打开时出现；可关闭或固定阅读，闲置两分钟自动收起。奖励按完成状态去重。

## 知识内容

- **174 个独立知识主题**。
- **22 类可操作实验**，多个主题共享相关实验，不冒称 174 个不同实验。
- **14 个年代条目**，继承明确注明的 ICS 2024/12 冻结版本；不是完整地质年代表，宙与纪区分显示。
- **20 类矿物、矿物组与铁合金数据**，不全是单一矿物种，更不是全部都叫矿石。
- **22 项研究 / 装备技能**。
- 方法覆盖观察、摄影测量、磁性/密度、XRF、XRD、微 CT、年代约束等。分析图注明教学合成，不能当真实标本检测报告。

保留每条知识的原有参考资料和科学边界。新增浅层沉积窗口为教学生成；深部通行、空间压缩和冲刺是科学幻想。现场位置、数据和装备参数不能用于现实登山、潜水、采矿或采集计划。

## 存档与旧版迁移

四个 localStorage 键为 `scoop-v13-玩法-难度-save`。页面所在浏览器允许本地存储时自动保存；查看器禁止存储时，本次会话仍保留四个档位，关闭页面前需要导出 JSON。

- 导入 **V11 JSON**：进入现代地球 / 探索档，保留已有路线、位置、收藏与知识，新增研究技能从基础开始。
- 导入 **V12 JSON**：当前区域是 `earth` 时迁入现代地球，否则迁入地标；保留其探索/地狱难度、各区路线、技能与报告。
- 导入 **V13 JSON**：按记录的玩法和难度恢复。
- 旧版 HTML 文件不是存档文件。需要先在旧游戏设置中导出 JSON，再在 V13 开场的“导入”入口选择。
- 导入会替换对应的那一个档位，其余档位不受影响。重开需要确认，且只重开当前选定档位。
- 不会擅自读取浏览器中别的页面或账号数据，不能恢复已经被清理的浏览器存储。

## 打开与构建

试玩只需要 `just_one_scoop_v13_complete.html`。所有角色、纹理、脚本、知识均内嵌，游玩无需网络；参考资料外链需联网。Android 的 `content://` 是本地文件交付地址，不是本游戏缺少外部图片的证据；不执行 JavaScript 的文件预览器无法运行游戏，应改用浏览器或自有静态托管。

开发源码在 `source/`。需要 Python 3，无第三方构建依赖：

```sh
python source/build.py just_one_scoop_v13_complete.html
```

核心仍为 World / DigController / Renderer / MapSystem / ScienceSystem，`journey.js` 负责现代航程，`session.js` 负责入口和档位隔离。不在页面末尾叠加覆盖旧渲染函数。

测试需要 Playwright、Chromium；并非试玩依赖。见 `QUALITY_REPORT.md`。

## 验收边界

这是带原创精灵与 WebGL/Canvas 程序材质的风格化 2.5D 游戏，不是 3D 实测地球或电影离线渲染。本轮重点是双主玩法、存档、现代完整航程和原有研究系统的实际整合。未完成全部 Android/iOS 真机、多浏览器版本、长时间性能/耗电、地质专家全面审校和商业发行验收。
